# Pacitum Browser 2.0.11-B

Pacitum 2.0.11-B improves animation smoothness and fixes visual glitches across the UI and refresh rate clocks.

---

## 🆕 New & Fixed in 2.0.11-B

### 🎬 Quick Switcher (`Ctrl+K`) Modal Animation
- **Fixed input text detachment during opening/closing:** The search input field (`QLineEdit`) is now dynamically synchronized with the card's vertical slide translation (`-10 * (1.0 - m_show)`).
- **Smooth fade transitions:** Added opacity effect to the search field so it fades in (140 ms) and out (110 ms) seamlessly alongside the modal card, eliminating the glitch where input text remained static and fully opaque while the card moved.
- **Graceful closing:** Query text and cursor stay visible and fade out smoothly when dismissed via `Esc`, `Enter`, or background click, rather than abruptly vanishing on the very first frame.

### ⏱️ High Refresh Rate Clock (`Motion::RefreshRateDriver`)
- **Accurate timer intervals for high-Hz displays:** Replaced integer truncation with rounded millisecond intervals (`qRound(1000.0 / m_hz)`). On 144 Hz displays (6.94 ms frame time), truncation caused a 6 ms timer (167 Hz, +16% extra timer wakeups); rounding produces a clean 7 ms (~143 Hz) pace.
- **Timer lifecycle safety:** Guarded `elapsed()` with `isRunning() && m_clock.isValid()` and invalidated the clock on stop to prevent stale timing offsets.

### 🔄 Tab Loading Spinner Smoothness
- **Eliminated 33 fps spinner judder:** Tuned the favicon spinner update throttle from 30 ms to 16 ms in `PacitumTabBar`. On 60 Hz and 120/144 Hz displays, a 30 ms interval resulted in uneven frame delivery (alternating between 33 ms and 50 ms); 16 ms aligns with the 60 fps frame budget for a fluid, silky spin.

### 📐 Overlay Drift Safety
- **Position restoration:** Reused `FadeOverlay` instances (such as back/forward page transition snapshots) now restore their base origin when finished or cancelled, preventing drift accumulation over repeated animations.
