# Pacitum Browser 2.0.4

Extension pop-ups work again, and Pacitum now carries its publisher's name.

## 🧩 Extensions
- **Pop-ups open reliably** (for example Enhancer for YouTube). When an extension is turned on, added, or its site access changes, Pacitum now reloads the open pages it works on. Before, those pages kept scripts that were cut off from the extension (`chrome-extension://invalid/` in the console), so the extension's features and its pop-up got no answer from the page.
- If Qt doesn't report an extension's pop-up, Pacitum reads it from the extension's manifest, as Chrome does.
- **Links in a pop-up open in a tab.** "Settings", "Help" and other links an extension pop-up opens now appear as a new tab instead of doing nothing.
- An extension button without a pop-up opens the extension's options page.

## 🏷️ Publisher
- Pacitum's installer, the app and the Linux packages now name **Next PRJ** as the publisher: in Windows' installed-apps list, in the file's Properties → Details and in the package information.

## 🍎 macOS no longer supported
- Pacitum is now built for **Windows and Linux** only. The macOS version is no longer built or released, and its macOS-only code was removed. Existing macOS installs keep working but won't get updates.
