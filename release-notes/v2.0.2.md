# Pacitum Browser 2.0.2

2.0.2 fixes pages that flash blank for a moment, and removes some work that ran on every page load.

## 🖼️ Pages that blink
- **The page (or part of it) could go blank for one frame, mostly while a heavy page like YouTube was loading.** Chromium, the engine that draws web pages, was pausing and re-showing the page whenever it thought another window was covering it, and redrew it from scratch each time. Pacitum now tells it to keep drawing the page at all times.
- **Tab previews no longer read back the live page while it loads.** The previews for the tab overview are only kept up to date once you have used the overview, and never while a page is loading. Before, this read-back ran for everyone a few seconds after every tab switch.

## ⚡ Faster
- **The tab's loading spinner repaints 30 times a second instead of 60.** Every repaint of the window also re-composes the page, so loading pages put less load on the GPU.
- **Clicking a button on a page without a sign-in form no longer scans the page** for password fields (video sites and web apps).
