# Pacitum Browser 2.0.2

Pacitum now installs on Linux like any other program.

## 🐧 Linux packages
- **`.deb` package** for Debian, Ubuntu, Linux Mint and other Debian-based systems:
  `sudo apt install ./PacitumBrowser-2.0.2-linux-x86_64.deb`
- **`.rpm` package** for Fedora and other RPM-based systems:
  `sudo dnf install ./PacitumBrowser-2.0.2-linux-x86_64.rpm`
- Both add a **Pacitum Browser** entry to the application menu and a `pacitum-browser` command, and can be set as the default browser. The app is installed in `/opt/pacitum-browser` and carries its own Qt and Chromium, so it needs only a few ordinary system libraries.
- Remove it with your package manager: `sudo apt remove pacitum-browser` or `sudo dnf remove pacitum-browser`.
- The **AppImage** is still available for Linux systems where you don't want to install anything.
- When an update is found, a Pacitum installed from a package downloads the `.deb` or `.rpm` for its own system (open the file to install it). The AppImage still updates itself.
