# Pacitum Browser 2.0.5

A crashing extension can no longer lock you out of a profile, and custom themes stay put.

## 🛡️ Extension crash safety
- **Pacitum recovers by itself when an extension makes it crash.** Adding Tampermonkey could make a profile crash on every start, and the only way out was deleting the extension's folder by hand. Now, if a profile closes unexpectedly right after starting (twice in a row, or once with a crash report), Pacitum moves the most recently added extension aside and starts normally.
- A message tells you which extension was turned off. You can remove it from **Extensions** or try adding it again later; its files are kept in the profile's `extensions-quarantine` folder.

## 🎨 Custom themes
- **Your custom theme stays after switching profiles.** Leaving a profile and coming back, or restarting Pacitum, could reset a custom theme to the Pacitum theme. The profile's own theme is now loaded before the window is drawn, every time.
