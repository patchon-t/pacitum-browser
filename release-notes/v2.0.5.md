# Pacitum Browser 2.0.5

Tampermonkey works, crash reports help fix bugs faster, a crashing extension can no longer lock you out of a profile, and custom themes stay put.

## 🧩 Tampermonkey works
- **Fixed a crash with extensions such as Tampermonkey.** Pacitum crashed while reading the toolbar icons of extensions that come with several icon sizes, and since it does that at every start, the profile crashed every time. Tampermonkey now installs and runs.

## 🛡️ Extension crash safety
- **Pacitum recovers by itself if an extension ever makes it crash.** Adding Tampermonkey could make a profile crash on every start, and the only way out was deleting the extension's folder by hand. Now, if a profile closes unexpectedly right after starting (twice in a row, or once with a crash report), Pacitum moves the most recently added extension aside and starts normally.
- A message tells you which extension was turned off. You can remove it from **Extensions** or try adding it again later; its files are kept in the profile's `extensions-quarantine` folder.

## 📮 Crash reports
- **When Pacitum closes unexpectedly, it can tell the developers.** At the next start Pacitum asks once whether to send a crash report: *Send automatically from now on*, *Send this time* or *Don't send*.
- A report contains what went wrong, your Pacitum, Qt, Chromium and system versions, and Pacitum's log of that session. Before sending, page addresses are shortened to the site name (no paths or searches), and your user name and e-mail addresses are removed from the logs.
- Change it any time in **Settings › System › Send crash reports**.
- **Help › Report a problem** now sends your description together with the log of the current session.

## 🎨 Custom themes
- **Your custom theme stays after switching profiles.** Leaving a profile and coming back, or restarting Pacitum, could reset a custom theme to the Pacitum theme. The profile's own theme is now loaded before the window is drawn, every time.
