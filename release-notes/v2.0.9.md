# Pacitum Browser 2.0.9

Tabs behave when you drag them, the bookmarks bar shows each site's own icon, and bookmark text is clean and easy to read.

## 🗂️ Dragging tabs
- **The tab you drag stays selected when you let go.** On Windows, letting go over the next tab selected that tab instead.
- **A tab's title is no longer cut short after a drag.** The end of the title used to show through after a faded gap (for example "Clau  le") until the mouse passed over the tab.
- **The close button follows the selected tab straight away.**

## 🔖 Bookmarks bar
- **Each bookmark shows its site's icon**, as you see it in the tab. It used to be the same globe for every bookmark. Icons are remembered from the sites you visit; for a bookmark you haven't opened yet, Pacitum fetches the site's icon once. Private tabs don't save icons.
- **Bookmark text is regular weight and a little larger**, so it is as sharp as the rest of the toolbar. It was drawn medium weight, which looked bold and blurry on Windows.
