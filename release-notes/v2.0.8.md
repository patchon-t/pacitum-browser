# Pacitum Browser 2.0.8

A big round of fixes: private tabs keep nothing, nothing closes Pacitum by surprise, your passwords and bookmarks are safer, and many everyday things work as they should.

## 🕶️ Private tabs keep nothing
- **Addresses you type in a private tab are no longer saved to history.**
- **A closed private tab can't come back** with Ctrl+Shift+T or on the new tab page.
- **Downloads work in private tabs.** They show in the downloads list for now and aren't saved to it.
- **Tracker blocking and "Do Not Track" work in private tabs too.**
- The **"Private —" label stays on the tab** after the page loads, and the private badge shows only while a private tab is on screen.

## 🛟 Safer data
- **Saved passwords can't be wiped by a file that fails to open.** The file is kept aside instead of being overwritten. The same goes for saved addresses and cards, and for a damaged bookmarks file.
- **Sync can't empty your bookmarks** when Google Drive comes back empty or you sign in with another account.
- **"Clear when Pacitum closes" waits for the last window.** It used to clear while another window was still open.
- **"Clear cookies" now also clears what sites store** (local storage and similar) the next time Pacitum starts.
- **Two windows no longer overwrite each other's open tabs or notes.**
- **The Google sync sign-in is stored encrypted**, like your saved passwords.
- **On Linux, showing, copying or exporting saved passwords asks for your computer password.**
- **Turning off that password check needs the password.**

## 🧯 Crashes and stuck states
- **Fixed: "QR code for this page" closed Pacitum** on very long addresses.
- **Sync no longer gets stuck "syncing"** when the connection stalls.
- **The Linux update keeps the old version** if the new one can't be put in place.
- **A crash no longer turns off an extension** that has been working fine since before the last good run.

## 🌐 Everyday browsing
- **Tracker blocking no longer breaks normal pages.** It used to block ordinary images named "banner", parcel tracking pages and similar.
- **Sites without HTTPS can be opened.** With "Always use secure connections" on, such a site now shows a bar to continue to the insecure address.
- **New History window** (Ctrl+H): search, open, remove entries or clear everything.
- **History is cleaner.** It saves the real page address and its title, not the words you typed, and keeps the last year.
- **Ctrl+N (new window), Ctrl+R (reload) and Ctrl+U (page source) work.** The menus showed them, but they did nothing.
- **Find in page** has proper buttons and shows "2 of 5".
- **Tab overview** shows the start of each page, previews of background tabs, and the port in addresses.
- **A program download asks once**, not three times. Two downloads of the same file no longer share one file.
- **Typing `mailto:` links or file paths** (like `C:\file.html`) in the address bar opens them.
- **Search suggestions no longer receive addresses you type.**
- **The window opens no larger than your screen.**
- **Typing a site on the extension page** is no longer wiped when the page refreshes.

## 🔒 Under the hood
- **The updater uses the project's current GitHub address.**
- **Logs are written for every Windows user name**, including Thai and other non-Latin names.
- **User scripts run in their own space**, apart from Pacitum's password helper.
- **An extension from the Chrome Web Store must have the ID you asked for**, or it isn't added.
- **Settings › Privacy › Safe browsing describes what it really does:** it asks before downloading programs.
- **Spell check isn't turned on when no dictionaries are installed.**
- **Crash reports can go through the Pacitum Discord bot**, so no webhook address has to ship inside the app.

## 🤖 Discord bot
- **Keeps announcing releases after an error**, and announces a release published while it was offline.
- **Bug reports can't ping people on GitHub.**
- **/release and /post-release check the version** and say so when GitHub can't be reached.
- **New, optional crash-report relay** (see the bot's README).
