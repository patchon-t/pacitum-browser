# Pacitum Browser 2.0.11

Pacitum 2.0.11 is a stability release for Linux fixing a critical crash during HTTPS page navigation.

---

## 🆕 New & Fixed in 2.0.11

### 🛡️ Linux: Fixed HTTPS Crash (`SIGTRAP` in NSS certificate verification)
- **Problem:** On newer Linux distributions (such as Ubuntu 24.04+, Debian, and Fedora), navigating to any HTTPS website crashed the browser within seconds with `Signal 5 (TRAP)` in thread `ThreadPoolForeg`.
- **Cause:** `linuxdeploy` bundled partial NSS libraries (`libnss3.so`, `libnssutil3.so`, `libnspr4.so`) without the cryptographically matching backend modules (`libsoftokn3.so`, `libfreebl3.so`). When Chromium initiated TLS certificate verification (`crypto::EnsureNSSInit()`), NSS dynamically loaded the host system's `libsoftokn3.so`, encountered an internal ABI clash, and failed initialization with error `-5977`. Chromium treated this as fatal (`LOG(FATAL)`), terminating the browser with `SIGTRAP`.
- **Fix:**
  - Removed bundled partial NSS and NSPR libraries from `.deb`, `.rpm`, and AppImage builds so the complete, consistent host system NSS suite is used.
  - Added system NSS preload detection into the `/usr/bin/pacitum-browser` launcher so existing installs seamlessly use the host's NSS modules.
  - Added `libnspr4` / `nspr` as explicit package dependencies alongside `libnss3` / `nss`.
