# Pacitum Browser 2.0.9-A

A fixed build of 2.0.9 for Linux: the .deb and .rpm packages now open on more systems, and when something stops the browser from starting, it tells you instead of doing nothing.

## 🐧 Linux packages (.deb / .rpm)
- **Fixed: on some Debian-based systems Pacitum installed but never opened.** Ubuntu 24.04 and systems built on it (Linux Mint 22, Pop!_OS, Zorin OS…) block the sandbox Chromium uses unless the app has a permission profile. The package now brings one (AppArmor) and installs it where it's needed.
- **If the browser still can't start, it tries again in a safe mode.** This covers computers without working 3D graphics, such as many virtual machines: software rendering, and without the sandbox only when the system doesn't allow it. A message points to the log if it still can't open.
- **A log for every start**: `~/.local/share/Pacitum/Pacitum Browser/launch.log`. Starting Pacitum with `PACITUM_SAFE_MODE=1` goes straight to safe mode.
- **The packages say what they need.** Pacitum needs a system from 2022 or newer: Debian 12, Ubuntu 22.04, Fedora 36 or later. On an older system the installer now explains this instead of installing a browser that can't open.
- **Updates in the right order**: 2.0.9-A is seen as newer than 2.0.9 by Pacitum's updater, apt and dnf.

Windows: the same browser as 2.0.9 (only the version number changes).
