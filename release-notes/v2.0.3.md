# Pacitum Browser 2.0.3

Smoother everywhere, and you decide what each extension may do.

## ⚡ Faster, smoother rendering
- **Animations follow your screen.** Tabs sliding, pop-ups opening and fades now run at your display's refresh rate (up to 240 Hz) on a precise clock, instead of Qt's coarse 60 Hz timer. On 120 / 144 Hz screens motion is noticeably smoother, and on 60 Hz screens frames are evenly spaced.
- **Busy pages slow other tabs down less.** On computers with 16 GB of memory or more, Pacitum lets Chromium run more page processes (12 with 16 GB, 16 with 32 GB, was 8), so one heavy tab shares its process with fewer others.

## 🧩 Full control over extensions
Open **Extensions → Details** on any extension:
- **Site access** now works, for Chrome extensions and Pacitum user scripts:
  - **When I click it:** the extension does nothing until you click its toolbar button on a site. That site is then allowed until Pacitum closes, and the page reloads so the extension can work.
  - **On sites I choose:** add the sites it may use (for example `youtube.com`). It runs nowhere else.
  - **On all sites:** every site the extension asks for, as installed.
  - An extension never gets a site it didn't ask for, and choosing **On all sites** puts it back exactly as it was installed.
- **Allow in private tabs:** turn an extension on for private tabs. It's off by default, so nothing an extension does there is kept unless you allow it.
- Reload open pages after a change to apply it.
