# Pacitum Browser 1.9.1

A fix release for the Qt 6.11 edition, mainly for **Chrome extensions**.

## 🧩 Chrome extensions
- **Turning an extension on crashed Pacitum** (1.9.0). Pacitum froze and closed as soon as you clicked **Enabled**. Extensions now switch on and run.
- Extensions from the Chrome Web Store keep their **real Chrome ID**. Extensions that talk to their own website or other extensions now work, and **Add to Pacitum** no longer shows for an extension you already have.
- **Enabled**, **Pin to toolbar** and **Remove** in the 🧩 menu now run after the menu closes.

> **Added an extension in 1.9.0?** Remove it from the 🧩 menu and add it again from the Chrome Web Store. Pacitum 1.9.0 put it in a place 1.9.1 no longer reads.

## 🔄 Updates
- **Clicking "Update" no longer closes Pacitum**, and if the update helper can't start, Setup opens with its own window.
